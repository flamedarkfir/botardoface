# Botardo Face App

**Botardo Face App** es una solución web de reconocimiento facial diseñada para potenciar y transformar la interacción en entornos educativos. Desarrollada por estudiantes del taller de Sistemas Informáticos del **Colegio Luis Madina** (Cali, Colombia), la aplicación permite experimentar con algoritmos de Inteligencia Artificial de forma rápida, accesible y 100% segura desde cualquier navegador.

### Puntos clave

* **Acceso Web 24/7:** Funciona sin necesidad de instalaciones locales o software adicional.
